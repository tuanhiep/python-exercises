# Python Exercises

Python practice problems for implementation fluency and interview preparation.

## Purpose

This repository is a personal exercise bank. It supports repeated practice with Python syntax, algorithms, data structures, and problem-solving patterns.

## Contents

- Standalone Python exercise files.
- Algorithm and data-structure problems.
- Small examples that can later be grouped into topic folders.

## How To Use

Run individual files directly while practicing.

```bash
python <exercise_file>.py
```

## Status

Active learning repo. The next upgrade is to add tests and group problems by topic, difficulty, and pattern.
